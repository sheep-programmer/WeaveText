# 织文输入法 0.1.0-beta.20

## 更新内容

- English 语音档位现在只使用能明确指定英文的识别模型，避免选择 English 后仍把英文识别成中文；英文终稿会过滤中文结果。
- 英文识别结果按正常英文大小写输出：普通词默认小写，保留 `I`、`USB`、`API` 等缩写，完整句子按句首规则恢复大写。
- 中英混合语音在安装了 SenseVoice 时会补做终稿识别，提高英文和中英混说的准确率。
- 修复语音字幕在较矮键盘区域中压住语言档位或被底部裁掉的问题。
- Mac 增加可配置的语音快捷键和语音悬浮窗；窗口保持打开直到手动关闭，停止录音后文字仍可确认、复制或上屏。
- Mac 手写窗、候选窗和语音窗改为不抢输入焦点的交互浮窗，修复点击手写窗后窗口消失、展开候选后滚动导致窗口消失的问题。
- Mac 候选翻页新增 `[ ]` 选项。
- Mac 增加从设置页直接打开表情收纳袋的入口；输入法菜单中也保留表情收纳袋入口。
- 手机悬浮表情收纳窗支持从四角拖动缩放并记住大小，键盘高度变化后恢复用户尺寸；Mac 收纳窗支持任意边缘缩放，紧凑布局也保留手动设置的窗口大小。
- 缩放角增加系统手势排除区域，修复收纳窗贴近屏幕边缘时返回手势抢走拖动、取消缩放的问题。
- 收纳袋的单张和批量删除统一增加二次确认，取消保留原图；弹窗沿用现有主题与按钮风格，小窗中的说明可滚动，操作按钮保持可见。
- 加强互联授权：取消配对会立即撤销已有连接，已移除或未信任的设备不能继续发送文字、剪贴板和文件；同时修复快速取消配对时的锁死问题。

包含统一 Android arm64 APK，以及 Apple Silicon／Intel 通用 Mac DMG。

## What's new

- English voice mode now uses only recognizers that can explicitly force English, preventing English speech from being decoded as Chinese; Chinese transcripts are rejected in English mode.
- English output now follows normal casing: ordinary words are lowercase by default, while `I`, `USB`, `API` and similar acronyms are preserved; sentence-initial capitalization is restored when appropriate.
- Mixed Chinese-English voice input performs a final-pass decode with SenseVoice when available, improving English and code-switched accuracy.
- Fixed compact voice captions overlapping the language selector or being clipped at the bottom of the keyboard.
- Added a configurable Mac voice shortcut and a persistent floating voice window. Stopping recording keeps the draft available for review, copying or committing until the window is closed.
- Mac handwriting, candidate and voice windows now remain interactive without taking keyboard focus from the text client. Fixed handwriting windows disappearing on click and expanded candidate windows disappearing while scrolling.
- Added `[ ]` as a Mac candidate paging option.
- Added a direct sticker-bag button in Mac settings; the input-source menu also keeps the sticker-bag command.
- The Android sticker overlay can be resized from all four corners and remembers its preferred size across keyboard-height changes. The Mac window resizes from every edge and preserves its manually chosen size when switching layout density.
- Sticker resize grips exclude conflicting system gestures, preventing Back from cancelling a drag when the window sits against a screen edge.
- Single and batch sticker deletion require confirmation. Cancelling preserves the originals, and compact-window confirmations keep the action buttons visible while allowing the description to scroll.
- Strengthened WeaveLink authorization: forgetting a peer immediately revokes its live connection, so removed or untrusted devices cannot continue sending text, clipboard data or files; also fixed a lockup during rapid revocation.

Includes one Android arm64 APK and a universal Apple Silicon / Intel Mac DMG.
