# 织文输入法 0.1.0-beta.21

相较 beta20（标签指向 `7185f18`），本版本包含 `f0d29af` 与 `962dc31` 两次提交的整批更新，完善手机与 Mac 的输入体验、互联和可选插件。

## 更新内容

- **双端输入、纠错与学习**：完善常见错拼纠正与近期选词排序，明确选择的完整词句、简拼和云词均可学习；选错后立即退格会撤销本次学习。Mac 补齐搜狗双拼、五笔选项和用户词导入导出，纠错与学习默认开启。
- **带声调候选拼音**：手机与 Mac 默认在候选词上方显示完整带声调拼音，可随时关闭；展开候选仅显示词语。
- **表情与收纳袋**：两端共享离线 Emoji、颜文字和中文名称，支持名称提示；收纳袋支持分组、收藏和备份互导。手机悬浮收纳窗可从四角缩放，Mac 可从边缘缩放，并保留用户尺寸；单张和批量删除均增加二次确认。
- **手写与浮窗**：手机改善连写分组，增加撤销重做、笔迹样式/粗细/颜色设置，单字候选扩至 30 个；可关闭停笔自动上屏。悬浮键盘支持四角或指定角缩放、贴边避让和横竖屏分别保存位置；Mac 手写连写偏好可保存并即时同步。
- **语音改进**：手机中文默认结合实时字幕与终稿复核；点按录音可停顿思考，再次点按才停止，波纹反映实际音量。修复立即重录和跨输入框迟到结果的问题；Mac 补齐语音插件配置，最多三个引擎共享录音，并延长停止后的终稿等待。
- **GitHub 插件仓库**：可指定仓库、分支和插件目录，也支持 Release 附件与源码目录；私有仓库可使用 Fine-grained、`Contents: Read-only` 令牌登录。令牌分别加密保存在 Android Keystore 或 Mac 钥匙串，不参与互联同步。
- **扫码配对与跨网直传**：新增手机扫码入口。跨网连接需要双方生成并交换连接码，再各自粘贴对方连接码连接；扫码读取一方连接码后，仍需将另一方连接码发回。STUN 仅探测公网地址，UDP 双向打洞后使用 QUIC 加密直传文件，不经过中继；对称 NAT、防火墙或封锁 UDP 的网络可能无法连接，网络变化或连接码过期后需重新交换。
- **独立离线翻译插件**：默认使用 Google 官方网页，译文需手动复制返回。离线功能需单独安装插件并准备语言包：Android 在 Google 插件中下载/删除，Mac 的 Apple 适配插件需 macOS 15+，语言包由系统管理。Android 主应用不内置 Google 翻译 SDK，缺包不会自动下载；同时修复旧版 Android 的插件签名校验兼容性。
