# 织文输入法 0.1.0-beta.23

本版本修复手机版按键震动的兼容路径与设置预览，沿用正式签名，可覆盖升级并保留设置与词库。

## 修复内容

- **统一触摸反馈用途**：轻、中、强以及光标滑动的刻度反馈均声明为触摸反馈。Android 8–12 使用对应的音频属性，Android 13+ 使用振动属性，修正此前不同档位标记不一致的问题。
- **硬件能力回退**：支持触感原语的设备保留短促的原语效果；轻档不再要求设备同时支持尾随刻度。Android 10+ 的其他设备使用系统校准效果，不再把振幅控制能力误当作系统效果的前提；Android 8–9 使用兼容短脉冲。
- **设置反馈**：点击档位保存设置并预览一次。系统触摸振动关闭或设备没有可用振动马达时，页面显示具体原因；系统设置变化后可即时更新。保持系统触摸反馈开关的行为，不绕过系统策略。
- **取消与异常恢复**：关闭档位、离开页面及系统关闭反馈时，丢弃尚未发送的振动和刻度任务；修复待发送任务读到关闭档位后误建强档效果的问题。厂商拒绝某种效果时回退到简单效果，避免反馈线程因异常停止。

- 独立翻译插件保持 Google `0.1.0`、Apple `1.0.0`，无需因本次震动修复重新安装。
