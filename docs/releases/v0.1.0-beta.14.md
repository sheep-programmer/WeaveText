# 织文输入法 0.1.0-beta.14

- 云端词旁增加蓝色云朵：覆盖 Android 候选栏、展开列表和 Mac 候选窗。学习标记与云词标记分开，读屏也能识别来源；已有本地整词不会被误标成新增云词。
- 云词下载／载入时增加转圈反馈，设置页提供失败重试和来源许可入口。关闭或重新开启后，旧更新不能覆盖新状态；签名失败保留已验证的数据。
- 云端词库从 2 个示例更新至 1264 个有效词，包括万象补充词、THUOCL IT 术语和自主整理的 AI／输入法术语。已经开启云词的用户可在“词库 → 云端热词 → 立即更新”取得词库；蓝云显示需要本版本。
- 保留万象 CC BY 4.0 署名及修改说明、THUOCL MIT 声明，原有自主词仍为 CC0。完整来源、固定版本及复现摘要随公开数据发布。

已验证云词与本地词去重标记、整句、学习与卸载、实际 JNI 快照／分页、明暗主题显示、点击／长按及更新取消回归；实际发布词表通过客户端内置公钥验签。“时间复杂度”“正则表达式”“上下文工程”在实际词库中可选并带蓝云。

这是签名词表下载与本机解码，保持默认关闭，不向云端提交每次输入或个人词频。Mac 功能继续使用系统输入法菜单。

包含 Android Lite、离线语音运行库版及 Mac 通用 PKG／DMG。来源与实现说明见 [云词调研](https://github.com/sheep-programmer/WeaveText/blob/main/docs/research/07-cloud-words.md) 和 [数据许可](https://github.com/sheep-programmer/weavetext-hotwords/blob/main/SOURCES.md)。
