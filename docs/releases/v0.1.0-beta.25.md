# 织文输入法 0.1.0-beta.25

本版本重做组词编辑（插入点、按音节编辑、以词取字、字形筛选与拆字查字），新增表情与剪贴板搜索、手写连写成行，并换上新的搭配模型；这一版修好光标面板键位重叠与表情、剪贴板面板无法输入搜索词的问题。沿用正式签名，可覆盖升级并保留设置与词库。

## 更新内容

- **组词中编辑**：全拼、双拼与英文组合串里可以移动插入点——手机点按或拖动预编辑行、在空格上滑动，外接键盘 ←／→、Home／End、Delete；Mac 点击文档里的拼音、竖排候选时 ←／→ 移动插入点。按音节编辑：手机外接键盘 Ctrl+←／→、Mac ⌥←／⌥→ 按显示的音节跳（双拼按全拼音节），加退格或 Delete 删掉插入点前／后一个音节。新键插在插入点；选定一部分词后紧接着退格可把刚选的词还原为拼音，连续退格按相反顺序逐个撤回。`[`／`]` 取高亮候选的首字／末字（手机长按候选菜单同样有「只上屏首字／末字」），取字按它自己的读音记入学习。展开候选可只看单字。九键、五笔、手写与 v 模式不提供插入点。
- **字形筛选（辅助码）与拆字查字**：拼音后按 `` ` `` 再输入笔画（h 横 s 竖 p 撇 n 点 z 折）或部件拼音的开头（时 = 日寸：`r`、`rc`），只留下首字或末字对得上的候选，次序不变。手机展开候选下方有「一丨丿丶乛」笔画键，预编辑里笔画显示为笔形。u 模式里以 u 开头、后打部件拼音或笔画查不会读的字：`ukoukoukou` = 品、`uhs` = 十，候选注出带声调的读音。两端一致。
- **候选与学习**：长按候选（Mac 右键）可「置顶这个词」，直到恢复默认排序；同一个词被「降低优先级」后再选中，降频即作废。学过的词可以带进更长的句子：被选中并顶替过系统首选的词，会让含它的长词让位（选过一次不算，单字不外溢，选回原词两次即恢复）。同音词不再被主词库挤掉。
- **搜索**：符号面板停在表情或颜文字分类时，网格上方出现搜索行，点一下铺开面板自带的字母键，按中文名、英文名与无声调拼音离线匹配（`weixiao`、`wei'xiao`、`weix` 都命中「微笑」，多词需逐词命中），回车取第一个结果，退格删空或返回退出搜索；Mac 表情库窗口有同一套搜索。剪贴板与常用语面板表头新增放大镜，点开后同样可以就地打字（字母、数字、`, .` 都进查询），字母与数字进查询、回车上屏第一条；中文内容也能按拼音搜到（打的拼音交给内核读成词再匹配，不上屏也不学习）。外接键盘在搜索展开时直接打词，方向键与快捷键照旧交给应用。
- **手写**：连写改为「写完一行再确认」——横向写 2–4 个字一起识别，停笔不再自动上屏，点候选确认，手机一行最多留 256 笔。停笔时间的两种用途分开：此前关闭「停笔自动上屏」会让书写区外那条容差永远成立，书写区边缘的按键按不到，现在判字时间始终是设置里的值。
- **键盘与光标**：光标面板改为 5 × 4、每格一键（此前左右键跨两行，会压住底行的撤销与重做），新增剪切；「选择」模式的左右键真正按下 Shift 再发方向键，普通文本框里扩选从此可用，撤销与重做交给编辑器（网页字段与终端退回 Ctrl+Z／Ctrl+Shift+Z）。英文键盘双击或长按 Shift 锁定大写，切到中文即解除。悬浮外框收窄：顶条 48dp → 28dp、底边 48dp → 14dp，去掉调整大小提示文字，卡片上下少占 54dp。纵向网格只有纵向位移才作废点按，斜着轻点不再「点了没反应」。九键「1」键的 16 个标点不再被英文三格样式截成 3 个。剪贴板卡片动作不再误盖住「只看当前剪贴板」的卡片，常用语表头的图标与动作逐位对应，列表变短后滚动位置夹回范围。重新选词不再列出不成立的「只上屏首字／末字」。成对符号的右半边在有选区时替换选区。展开候选与设置列表的字号、无障碍播报随查询更新。
- **表情收纳袋**：管理页网格缩略图按 256px 解码，比原先更清晰；动图在管理页、键盘面板与 Mac 收纳窗里都会播放（此前只解第一帧，看着像静止图），存进收纳袋的仍是原文件。
- **中/英**：可按应用记住中／英——在某个应用里显式切过，回到它就还原；没切过的应用照旧按输入框类型给默认，密码框、纯数字框不参与。最多记 100 个应用，超出丢最早的，「输入方案 → 中/英」（Mac「中英切换」）里可一键清除。
- **搜索框与读音**：表情目录新增英文名与逐字拼音，离线生成，不联网、不加依赖。
- **内核与数据**：搭配模型来自上游 LTS 资产，该资产会被上游原地替换（本版发布当天又换过一次，两次都没有公开说明，旧字节上游不再提供），`data/build.sh` 按校验值固定当前版本；同一 1000 句评测集上首选整句 **75.7%**（前三 80.0%、字准确率 95.85%；小鹤 75.7%、九键 49.2%），前一版为 76.0% / 76.0% / 49.0%，属同一水平的小幅波动。字形表取万象拼音反查词典里的笔画与部件读音（CC BY 4.0），只收拼音字库里的字，压缩后约 0.8 MB。

## 下载与升级

- 手机：`WeaveText-0.1.0-beta.25-arm64.apk`，Android 8.0+、ARM64，沿用正式签名，可覆盖升级并保留设置与词库。包含离线语音运行库，语音识别模型按需下载。
- Mac：`WeaveText-0.1.0-beta.25-mac.dmg`，macOS 13+，Apple 芯片与 Intel 通用。打开 DMG 后按安装器提示操作；安装包未作 Developer ID 签名和公证。
- 可选 Google 离线翻译插件：`WeaveText-Google-Offline-Translation-0.1.0.apk`。
- 可选 Apple 系统翻译适配插件：`WeaveText-Apple-Offline-Translation-1.0.0.zip`，需要 macOS 15+。
- `SHA256SUMS.txt`、`SHA256SUMS-plugins.txt` 和 `SHA256SUMS-mac.txt` 分别提供对应文件的 SHA-256。

翻译插件保持独立版本，没有功能变化时无需重新安装。

## 验证与当前边界

发布前内核全量 **222 项**通过（3 项忽略；按 CI 的 `--features weave-dict/pack` 跑为 **223 项**），Android 全量 **977 项** 0 failures、`lintDebug` 0 errors，桌面 JNI **40 项**（15 项按需跳过），Mac 核心 **225 项**通过。新功能都带用例：字形筛选与 u 模式、组词编辑与按音节编辑、以词取字、退格撤回选词、置顶与降频恢复、长句继承、表情与剪贴板搜索、按应用中/英记忆、连写成行与判字时间，以及本轮修掉的几处界面缺陷（九键标点、剪贴板卡片动作、常用语表头图标、斜着轻点、成对符号右半边替换选区）。三条曾经的疑点先写出失败的用例再修，确认钉的是真实缺陷。面板搜索的两处缺陷在模拟器上先复现再修，并补了用例：字母与数字进查询而正文不动、空格与标点在空查询时归搜索框、搜索中上滑改写只改查询、实体键盘按键先给搜索框、退出搜索或换分类后行上不留旧词；光标面板新增逐键不重叠的布局检查。

两件「试过但没做」的事，都量过数字后放弃，未留代码与开关：停顿时的更宽重排（束宽 6 → 24、候选池 8 → 24 都让同一套评测集一字未变，单句耗时从 325 ms 涨到 1362 ms）；26 键滑行输入（真实键盘几何合成路径上，按划过格子解码逐字命中 0/125，按拐点解码最好 59/125，天花板测量目标词是划过键序列子序列的有 92%，难点是 nihao 与 niao 这类同样合法的读法要靠语言模型剪枝，内核只对给定的一串字母排序）。两者的数字与做法记在 [输入体验验证](../input-experience-verification.md)。

尚未包含：全拼分段选拼音、字形筛选的双拼辅助码方案（目前只有笔画与部件全拼）、字母键盘自身（不经光标面板）的多步撤销与重做、系统词库词的屏蔽、按音节编辑的触屏入口（内核与控制器已有，只有外接键盘与 Mac ⌥ 能触发）、Mac 的「关闭停笔自动上屏」开关、Mac 展开网格笔画键只做了映射与显示条件验证、Mac 本地语音模型资源准备。手机真实导航栏、连续切应用、真实录音尾音与 Mac 应用间焦点仍需设备验收；Mac 点击文档中的拼音放插入点依赖各应用报告字符位置，未在真实应用里逐个试过。
