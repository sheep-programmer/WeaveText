# 织文输入法 0.1.0-beta.22

本版本改善手机与 Mac 的输入、设置、下载和语音操作，新增独立公开插件市场。基础打字保留在输入法中，可选工具、主题与布局按需搭配。

## 更新内容

- **插件市场与设置**：两端新增分类、搜索、已添加筛选及启停入口；额外主题与手机布局通过市场安装和卸载，保留少量基础主题。市场资源支持大小／SHA-256 校验、缓存回退和取消；官方公开资源库为 [weavetext-market](https://github.com/sheep-programmer/weavetext-market)。手机市场入口采用普通设置卡片的字号与尺寸，Mac 设置增加概览并简化输入法菜单。
- **候选与注音**：默认隐藏拼音，开启后只在当前高亮词后用括号标注；候选与联想保持同一行高度。回车收起未选的联想词，候选栏的叉可清空联想。手机与 Mac 均可读取／复制完整长候选，旧候选或菜单不能作用到更新后的输入会话。
- **外接键盘**：手机支持上下键、Tab／Shift+Tab 导航候选及 PageUp／PageDown 翻页，数字对应当前九项页。高亮项自动进入可见范围；确认英文词时保留主动输入的空格，空闲联想不抢应用的 Tab 焦点和翻页滚动。
- **手机布局与手写**：改善切应用、旋转、浮动及导航栏变化后的避让，补齐旧 Android 的窗口接口兼容性守卫。手写增加标准、半屏和全屏可用区域；优化笔画收尾、取消和候选刷新。表情分类采用左侧主分类与顶部子分类，光标编辑入口更集中，深浅色快捷切换不再经过中间状态。
- **语音操作**：手机修复启动失败、立即重试、取消和迟到回调，停止／失败时保留已有文字，多引擎终稿可确认选择。Mac 支持取消准备和结束收尾等待，回收麦克风与插件会话；通过“文字 → 编辑草稿”在独立窗口编辑，完成后点选输入位置再上屏。
- **双拼与英文**：四套双拼支持有界英文片段，保留 `GitHub`、`API` 等原始大小写及英文后续的双拼边界；合法中文读法优先，字母原文可主动选择，回车保留原码。修正英文自动确认擅自改变原文的情况，混输学习按中文／英文分别保存并支持撤销。
- **更新与模型下载**：改进有期限的镜像探测、连接／读取取消、续传和损坏片段恢复；显示连接、下载、校验阶段以及字节量、总大小和速度。更新校验值绑定准确版本及文件，拒绝签名不一致的 APK；完整离线语音版下载也使用相同进度与取消流程。
- **内核与隐私**：减少解码和注音的重复分配，保留既有词库格式和原生接口；基础输入离线，可选联网能力保持明确入口。新增官方源码调研、独立实现记录及可复现验证说明。

## 下载与升级

- 手机：`WeaveText-0.1.0-beta.22-arm64.apk`，Android 8.0+、ARM64，沿用正式签名，可覆盖升级并保留设置与词库。包含离线语音运行库，语音识别模型按需下载。
- Mac：`WeaveText-0.1.0-beta.22-mac.dmg`，macOS 13+，Apple 芯片与 Intel 通用。打开 DMG 后按安装器提示操作；安装包未作 Developer ID 签名和公证。
- 可选 Google 离线翻译插件：`WeaveText-Google-Offline-Translation-0.1.0.apk`。
- 可选 Apple 系统翻译适配插件：`WeaveText-Apple-Offline-Translation-1.0.0.zip`，需要 macOS 15+。
- `SHA256SUMS.txt`、`SHA256SUMS-plugins.txt` 和 `SHA256SUMS-mac.txt` 分别提供对应文件的 SHA-256。

翻译插件保持独立版本，没有功能变化时无需重新安装。App 的“更新”和语音模型下载支持选择下载源；市场入口不会上传输入内容或私人 GitHub 凭据。

## 验证与当前边界

发布前 Android 全量 854 项、Mac 269 项检查通过；补做 56 项手写区域／导航／实体键盘检查，Android lint 无错误。代码基线 `d7f7c6a` 的远端 CI 也已通过，正式构建继续核对版本、签名、架构、词库与 JNI 依赖。

长串随机输入仍可能触发较高计算成本，现有组合长度检查不代表最坏延迟达标。普通字母键盘上的自动手写／滑行区分、组合串中间编辑、以词取字等尚未包含在本版本；真实手机录音与系统导航、Mac 应用间焦点仍需要设备反馈。
