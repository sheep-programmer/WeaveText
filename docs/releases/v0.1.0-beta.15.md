# 织文输入法 0.1.0-beta.15

- Android 工具栏新增“表情收纳袋”：相册／文件导入、系统“收纳到织文”分享接收、可读取的图片剪贴板及拖入。收藏、分组、标签搜索、最近使用、批量分组／删除和备份都在独立管理页完成。
- 可选悬浮收纳窗：授权后开启，可移动、展开、收起及关闭；避开键盘、导航按钮和显示边缘，横屏空间不足时收起。持续通知可关闭悬浮窗。
- GIF、动态 WebP 保留原始文件，以图片内容去重、识别真实格式，不受清空剪贴板历史影响。备份可以在 Android 和 Mac 之间导入，保留名称／分组／标签／收藏／最近使用。
- Mac 从系统输入法菜单打开收纳窗，支持小窗模式、拖入／拖出、剪贴板导入、整理和备份；没有额外菜单栏图标。点击复制原文件，已取得辅助功能授权时尝试粘贴到前台应用。
- Android 支持图片的编辑器可直接插入；不支持时打开系统分享。Mac 也可直接拖出原文件。仍需在目标应用确认发送；QQ／微信／抖音能否拖出及接受图片由其客户端版本决定，尚未逐版本实机验证。

参考 EmojiManager、MemeManager 的收纳交互和 OhMyMeme 的功能设计，以 Android／AppKit 原生 API 独立实现，未复制第三方源代码或表情素材。实现、来源许可和验证范围见[表情收纳袋调研](https://github.com/sheep-programmer/WeaveText/blob/main/docs/research/08-sticker-collection-feasibility.md)。

包含正式签名 Android Lite／离线语音运行库版，以及 Apple Silicon／Intel 通用 Mac PKG、DMG。两款手机版的离线语音识别模型仍需先下载。
