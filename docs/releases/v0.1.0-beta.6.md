## 织文输入法 0.1.0-beta.6（预发布 / Pre-release）

修复 beta.5 离线语音正式包加载所有识别模型时出现的 `failed to get field ID for decodingMethod` 错误。
语音库通过 JNI 按原名读取配置字段；现在保留这些类、字段和识别结果，防止正式构建改名或删除。
无需删除或重新下载已有模型，覆盖安装即可。

Fixes the release-only R8/JNI bug that prevented speech models from loading in beta.5. JNI config and result
classes and their fields now survive minification. Install over the previous version; existing models stay usable.
