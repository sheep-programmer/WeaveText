# 织文输入法 0.1.0-beta.8

- Android 语音改为离线模型：移除系统识别与云端语音后端，使用前先下载语音包。
- 键盘按导航栏实际重叠量避让，避免虚拟按键遮挡和重复抬高；悬浮键盘也避开横屏侧边导航栏。
- 点按开始、再次点击结束；停顿不会关掉麦克风，按住说话仍在松手后结束。
- 模型与麦克风真正准备好后才显示正在聆听；停止前交完最后一块音频，长句分段补齐末尾。
- 面板和浮动语音条显示实际麦克风音量波纹，轻声也能看到起伏。
- 新增 Dolphin 轻量、Dolphin 增强、TeleSpeech 中文方言与 Silero 人声检测。保留实时小/大模型、终稿小模型、SenseVoice、Paraformer 和标点选择。
- 两种 Android 包都要下载识别模型；Lite 推荐包下载约 33 MB，语音版已含运行库，推荐包约 24 MB。已有下载模型可继续使用。
- 包含 beta.7 的口语拼音「嗯嗯」「修吧」、手写比例融合与旧任务取消；Mac 设置和互联入口移入系统输入法菜单，取消独立菜单栏图标。

建议先使用「实时识别 · 小」。手机内存充足时可选择额外终稿模型，或在识别设置中关闭实时模型使用整句识别。识别错误仍可编辑；不要把少量样本通过当作所有口音都准确。
