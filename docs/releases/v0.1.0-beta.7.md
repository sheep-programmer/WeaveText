## 织文输入法 0.1.0-beta.7（预发布 / Pre-release）

修复短句与语气词输入，改善手写的连续落笔和比例容错，Mac 改为使用系统输入法菜单。
Improves conversational pinyin and handwriting; Mac commands now live in the system input-source menu.

### 变化 / Changes

- **嗯／嗯嗯**：源词库中的音节鼻音 `n`、`ng` 与带调拼写现在按常用输入 `en` 编译，词条不再被跳过；`enen` 可直接选择「嗯嗯」，不再因缺词被纠错吞字。
- **完整拼音保留候选**：补全或纠错胜出时，实际打出的完整音节仍保留整词／整句候选；`xiuba` 可以直接选择「修吧」，不必接受补成 `xiuban` 的候选。
- **手写**：低置信度笔迹同时检查略宽／略高两个视图，改善写扁和写长的字；高置信度仍只推理一次。新笔画不等待旧识别任务，过时任务和候选会被丢弃。
- **Mac**：取消独立菜单栏图标；切换到织文后，在系统输入法图标的菜单里选择「织文键盘设置…」；输入方案、中英、繁体和发送到手机也在同一菜单中。

### 安装包 / Packages

| 文件 File | 用途 |

### 验证与限制 / Validation and limits

- 真实词库经 Android JNI 与 Mac C 接口回归测试，覆盖「嗯」「嗯嗯」「修吧」的输入、候选与上屏。
- 1000 句拼音评测首选准确率保持 71.0%，前三命中率 77.0% → 77.6%（常用七组模糊音开启）。
- 本地外部笔迹文件的 2000 条样本首选 66.0% → 67.0%，前五 83.5% → 84.1%；额外视图会增加低置信度字的后台 CPU 耗时，非所有设备的准确率保证。
- Mac 系统菜单的鼠标行为由 macOS 管理；输入法提供菜单内的设置命令。不同客户端的实际菜单与手写跟手感仍需实机验证。

数据许可见 `docs/THIRD_PARTY.md`。
