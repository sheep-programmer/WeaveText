## 织文输入法 0.1.0-beta.1（预发布 / Pre-release）

首个公开测试版，支持 Android 8.0+ 的 arm64 设备。仍在测试阶段，欢迎反馈。
First public test build for Android 8.0+ on arm64. Still in testing; feedback welcome.

### 下载哪个 / Which APK

| 文件 File | 说明 Notes |
|---|---|
| `WeaveText-0.1.0-beta.1-arm64-lite.apk`（约 30 MB） | **推荐。** 全部输入功能；词库直接从安装包读取、不再解压，装机占用约等于安装包大小。语音输入使用系统识别或插件。 *Recommended: every input feature, dictionaries read straight from the APK (footprint ≈ APK size); voice via the system recognizer or plugins.* |
| `WeaveText-0.1.0-beta.1-arm64-voice.apk`（约 146 MB） | 在轻量版基础上内置端侧离线语音识别（语音不离开手机），可再下载更准的模型。 *Adds on-device offline speech recognition; larger models are optional downloads.* |

两个包签名相同，可以互相覆盖安装。`SHA256SUMS.txt` 为校验和；安装包由 GitHub Actions 从本仓库源码构建。
*Both share one signature and can replace each other. `SHA256SUMS.txt` holds checksums; the APKs are built from
this repository by GitHub Actions.*

### 功能 / Features

- 全拼整句（简拼、模糊音、错拼纠正、中英混输）、双拼（小鹤 / 自然码 / 微软 / 搜狗方案）、九键、五笔 86、英文联想。
  *Full pinyin sentences, shuangpin, T9, Wubi 86, English suggestions.*
- 用户词学习、繁体输出、表情联想、剪贴板（默认关闭）、常用语、单手模式、键盘高度。
  *User learning, traditional output, emoji, clipboard (off by default), phrases, one-handed mode, height.*
- 键盘风格：6 套布局 × 16 套配色，可微调并导入/导出 `.wvskin`。
  *6 layouts × 16 themes, tweaks, `.wvskin` import/export.*

### 已知问题 / Known issues

- 主要在模拟器与桌面测试中验证，真机覆盖有限。 *Verified mainly on emulator and desktop tests.*
- 符号面板在所有布局下结构相同。 *The symbol panel shares one structure across layouts.*
