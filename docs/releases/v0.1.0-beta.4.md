## 织文输入法 0.1.0-beta.4（预发布 / Pre-release）

第四个测试版：拼音自动纠错并标红、模糊音默认开启、语音修复与模型一键切换、更耐变形的手写，macOS 版改为标准安装包。
仍在测试阶段，欢迎反馈。
Fourth test build: pinyin auto-correction marked in red, fuzzy pinyin on by default, voice fixes and one-tap model
switching, more forgiving handwriting, and a standard installer package for macOS. Feedback welcome.

### 下载哪个 / Which file

| 文件 File | 说明 Notes |
|---|---|
| `WeaveText-0.1.0-beta.4-arm64-lite.apk`（约 33 MB） | **推荐。** 全部输入功能；需要离线语音时在「语音包」里一键安装。 *Recommended.* |
| `WeaveText-0.1.0-beta.4-arm64-voice.apk`（约 67 MB） | 内置识别运行库与实时识别模型，装好即可离线说话。 *Ships offline voice.* |
| `WeaveText-0.1.0-beta.4-mac.pkg`（约 28 MB） | **macOS 推荐。** macOS 13+，Apple 芯片与 Intel 通用。双击，按安装向导走完（需输入一次管理员密码），装好自动选中「织文拼音」。 *Double-click and follow the installer.* |
| `WeaveText-0.1.0-beta.4-mac.dmg` | 同一个安装包放在磁盘映像里，打开后双击「双击安装织文输入法.pkg」。 *The same package inside a disk image.* |

安卓两个包签名相同，可互相覆盖安装，也可直接覆盖旧版，设置与学过的词都保留。
*Both APKs share one signature and install over each other and older builds, keeping settings and learned words.*

### 新变化 / What's new

- **自动纠错**：字母打颠倒（xain → xian）、漏打（zhog → zhong）、多打（zhoong → zhong）时自动改正，拼音行里用红色标出改动：
  颠倒的两个字母上方一道弧线、补上的字母加下划线、多打的字母划掉。正常输入的准确率不受影响；可在「输入方案 › 自动纠错」关闭。
  *Swapped, missing and extra letters are fixed and marked in red in the pinyin line; clean input is unaffected.*
- **模糊音默认开启**常用 7 组（z/zh、c/ch、s/sh、n/l、an/ang、en/eng、in/ing），可自行增删。
  *Seven common fuzzy pairs on by default, editable.*
- **语音**：
  - 下载的识别模型装好就用上，「语音包」里标「使用中」，点「使用」随时切换（之前新下载的模型选不上）；
  - 只装 SenseVoice / Paraformer 等终稿模型也能用，说完一句整句识别；
  - 点按说话时开口前多等一会儿，说话判断随环境底噪自适应，声音小的手机不再说着说着就停；
  - 麦克风打不开、录到静音时自动换音源，录音出错会提示而不是一直停在「正在聆听」，系统识别没听清也会提示。
  *Downloaded models are used right away and can be switched with 使用; a final model alone works; tap-to-talk waits
  for the first word and adapts to the noise floor; mic fallbacks and clear errors.*
- **联想词**：退格或挪动光标时联想跟着收起，不再留下点了不上屏的旧联想；联想行整行居中。
  *Stale predictions are gone after backspace or cursor moves.*
- **手写**：写歪、写扁、连笔、断笔都更认得出（更像真人手写的变形评测：首选 59% → 85%）。 *More forgiving handwriting.*
- **macOS**：改为标准 `.pkg` 安装包，装到「/Library/Input Methods」并自动登记、选中；修复安装程序点「安装」没反应（崩溃）的问题；
  英文系统里也叫「织文拼音 WeaveText」，好找；设置 › 关于 可卸载。
  *A standard installer package; the old installer crash is fixed; the input mode is easy to find on English systems.*

### 已知问题 / Known issues

- 主要在桌面测试与截图中验证，真机覆盖有限。 *Verified mainly on desktop tests and screenshots.*
- macOS 安装包未签名、未经 Apple 公证：首次打开若提示无法验证开发者，请到「系统设置 › 隐私与安全性」里点「仍要打开」；
  装好后输入法菜单里暂时没有「织文拼音」时，注销后重新登录一次。macOS 版的拼音行暂不画纠错标记（只显示改正后的拼写）。
  *The Mac package isn't signed or notarized: allow it in Privacy & Security; log out and back in once if 织文拼音
  doesn't show up yet. The Mac pinyin line shows the fixed spelling without the red marks for now.*
