## 织文输入法 0.1.0-beta.2（预发布 / Pre-release）

第二个测试版，重点是更小的安装包、更跟手的打字，以及轻量版也能离线语音。仍在测试阶段，欢迎反馈。
Second test build: smaller packages, snappier typing, and offline voice for the lite build too. Feedback welcome.

### 下载哪个 / Which APK

| 文件 File | 说明 Notes |
|---|---|
| `WeaveText-0.1.0-beta.2-arm64-lite.apk`（约 30 MB） | **推荐。** 全部输入功能；词库直接从安装包读取，装机占用约等于安装包大小。需要离线语音时在「语音包」里一键安装（约 30 MB）。 *Recommended; install offline voice from the voice-pack list (~30 MB) when needed.* |
| `WeaveText-0.1.0-beta.2-arm64-voice.apk`（约 64 MB） | 内置识别运行库与实时识别模型，装好即可离线说话。 *Ships the speech runtime and streaming model.* |

两个包签名相同，可互相覆盖安装，也可直接覆盖 0.1.0-beta.1，设置与学过的词都保留。`SHA256SUMS.txt` 为校验和。
*Both share one signature and install over each other and over 0.1.0-beta.1, keeping settings and learned words.*

### 新变化 / What's new

- **安装包更小**：词库改为分块压缩、从安装包直接读取，不再解压到手机；轻量版 76 → 30 MB，离线语音版 160 → 64 MB。
  *Block-compressed dictionaries read straight from the APK; lite 76 → 30 MB, voice 160 → 64 MB.*
- **打字更跟手**：多指独立跟踪（快速双手连打不丢字）、按下即出字、候选每帧只刷新一次、长按不再误出数字、空格滑动后照常上屏、
  退格与自动大写少走进程间通信；每键构造的候选从平均 261 个减到 120 个以内。
  *Per-finger tracking, emit on press, one render per frame, no accidental digits, fewer editor round-trips.*
- **轻量版离线语音**：「语音包」逐项安装、卸载——识别运行库、实时 / 终稿识别、智能标点；推荐组合一键安装约 30 MB。
  *Voice packs installed and removed one by one on the lite build.*
- **语音不再报错**：修复系统语音识别在 Android 11+ 连不上的问题；没有可用引擎时给出安装引导，或一键切换到手机上其他的语音输入法。
  *Fixed the system recognizer on Android 11+; guidance instead of errors, or a one-tap switch to another voice IME.*
- **新布局与功能**：14 键拼音、宽屏分体键盘、带数字行的布局、悬浮键盘（可拖动、可缩放）、多个语音引擎同时识别并从结果中选择、
  外接实体键盘、五种自带按键音；默认键盘更高、按键震动默认关闭。
  *14-key pinyin, split layout, number row, floating keyboard, multi-engine voice, physical keyboards, key sounds.*
- **修复**：语言模型、简繁表、表情表此前未装到手机上，整句准确率与繁体、表情功能现已恢复正常。
  *Fixed: the language model, conversion and emoji data were never installed on the device.*

### 已知问题 / Known issues

- 主要在桌面测试与截图中验证，真机覆盖有限；轻量版下载运行库后在手机上载入这一步尚未在真机验证。
  *Verified mainly on desktop tests; loading the downloaded runtime on a real phone is not yet verified.*
- 14 键存在同键字母的天然歧义（如 chi / chu），需从候选中选择。 *14-key has inherent ambiguity between paired letters.*
