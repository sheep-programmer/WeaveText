# 织文输入法 0.1.0-beta.9

- Android 语音面板下拉可勾选 1–3 个已下载的离线识别模型；同一份录音并行识别，停止后分行显示结果，点选一行上屏。相同结果也保留，不自动替你选。
- 新增真实中英双语 Zipformer 标准、增强实时模型，以及 WeNet 中英粤语整句模型；中文、英文与混说按模型能力识别，英文分句之间保留空格。
- 下载页提供轻量中文、中英标准、中英增强三个档位。增强档使用双语增强与 SenseVoice 两个模型，结果分别展示。
- 修复空格长按容易被轻微手指漂移打断，以及模型冷启动期间没有录到声音的问题。麦克风立即收音，加载期间缓存音频，松手后处理已经收到的语音。
- 声波显示真实麦克风音量，低音量可见，较响的声音也保留起伏；数字静音保持平直。
- 修复双语模型压缩包里同名上下文文件覆盖根目录文件，导致解压或校验失败的问题。
- 两种 Android APK 均需下载识别模型；Lite 另下载运行库。标准双语官方压缩包约 358 MB，安装所选模型约 50 MB；增强双语包约 347 MB，安装约 122 MB，另需 SenseVoice。下载界面显示所需流量。
- 同时提供 Mac 通用 PKG、DMG，保留系统输入法菜单入口与 beta.8 的打字、手写改进；本次语音交互升级在 Android。

使用：先在「语音包」安装中英标准或增强档，打开语音面板，下拉勾选最多三个已下载模型。点按语音键开始/停止，或长按空格说话，松手后点击结果行。

已用自然中英夹杂录音验证模型识别，并在正式 APK 中验证长按空格、三行结果、点选上屏和键盘完整删除。测试录音中保留了 ON TIME、IN TIME 与“准时”。标准模型在短录音、很轻的录音中仍有英文漏识别；其他拼接录音也有错词，识别准确率会随口音、环境和模型变化；可比较不同结果后再上屏。
