# 织文输入法 0.1.0-beta.13

- 修复 `ken` 被拆成 `ke'n`、误把“可能”放在“肯”前面：完整音节优先，手动输入 `ke'n` 仍支持简拼。
- 候选增加固定首选、取消固定、降低优先级和恢复排序。手机长按候选，Mac 右键候选；删除学习记录仍可用。固定候选在重新加载后保留，完整句子的候选不会被单字偏好挤走。
- 新增选中文字重新选词：手机在光标面板点“重新选词”，Mac 从系统输入法菜单点“重新转换所选文字”。只替换原选区；选区、输入框变化或取消时保护已有文字。
- 英文增加有计算上限的拼写建议，例如 `recieve → receive`，保留原拼写。点选英文不自动添加空格。
- 全拼支持中文与英文片段共同组句，例如 `jintianreviewzhegePR → 今天review这个PR`，保留英文大小写与词内撇号。完整中文读法优先，避免把“我们”“吃了”误当成 `women`、`chile`。
- 互联新增手动发送／合并个人资料，包含中英文用户词、近期选择、候选偏好、快捷短语与手写样本。通过已配对设备的加密通道传输，接收文件进入私有目录，点合并才生效。冲突结果一致，重复导入不增加词频，删除记录可传播。
- 离线语音增加可选个人热词与自定义人名、术语。适配的 Zipformer transducer 支持中文热词，标准中英模型还支持英文热词；更新词汇时创建新录音流，复用模型权重。默认关闭，全部在本机处理。
- 手写纠正记住个人字形，重启后仍保留，可清空。新增从左到右、字间留空的 2–4 字模式，由用户选候选确认；Mac 从系统输入法菜单打开手写窗口，无额外菜单栏图标。后台旧识别结果不会覆盖已清空或较新的笔迹。
- 常用语增加字母快捷码与模板；`{date}`、`{time}` 按本地时区展开，其他内容原样插入。

已验证核心回归、实际 JNI／Mac C ABI、Android 安装包内词库与输入控制器、双向加密个人资料及图片／文件传输。112 项 Android 输入逻辑测试通过；Lite 与语音运行库版正式 APK 均完成上述两次中英热词识别，签名与 JNI 校验通过；Mac 两种架构自检、测试与 DMG 校验通过。1000 句中文评测与 beta.12 相同：首选 75.6%，前三 79.8%，字符准确率 95.84%。这些数字仅对应仓库评测集。

语音热词使用与标准模型匹配的原始分词表；真实中英音频在同一识别器上连续两次识别并更新词汇，保留“准时 / ON TIME / IN TIME”。其他模型保持原识别，不套用不支持的热词接口。多字手写目前需要字间留空，尚不等于任意草书全句识别；重选依赖应用提供有效选区。

包含 Android Lite、离线语音运行库版，以及 Mac 通用 PKG／DMG（Apple Silicon 与 Intel）。Mac 仍使用 ad-hoc 应用签名与未公证安装包。

实现与使用说明见 [输入体验功能](https://github.com/sheep-programmer/WeaveText/blob/main/docs/personal-features.md)，研究来源见 [输入法优势调研](https://github.com/sheep-programmer/WeaveText/blob/main/docs/research/06-experience-opportunities.md)。
