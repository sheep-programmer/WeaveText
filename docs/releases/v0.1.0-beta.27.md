# 织文输入法 0.1.0-beta.27

本版本改进候选读音约束、触摸输入、手写、多语音结果与快捷输入，并重做 Android 翻译区和悬浮键盘交互。

This release improves candidate reading constraints, touch input, handwriting, multiple voice results and quick input, and redesigns Android translation and floating keyboard controls.

## 更新内容 / Changes

- **翻译收成一条窄栏**：Android 翻译区重做为键盘上方的单行窄栏——语言胶囊「中 › 英」、圆形功能钮、草稿胶囊（含清除钮）与「完成」钮；悬浮与停靠模式都一样，主键盘保持完整、照常打字进独立草稿，不挤压按键与候选区。点「完成」请求翻译，结果确认后写回（有选区替换、无选区插入）；读取选区、粘贴、复制、清空、网页翻译与插件管理收进圆形钮菜单。原文或语言变化使旧请求失效，输入位置变化后拒绝旧结果写回；密码等敏感输入框不提供翻译。默认官方网页入口和可选离线插件保持原有配置。
  *The Android translation area is now a single strip above the keyboard — a language pill, a round action button, a draft capsule with a clear button and a Done button. Docked or floating, the keyboard stays full-size and typing goes into a separate draft without shrinking keys or candidates. Done requests a translation and a confirmed result writes back (replacing a selection or inserting). Selection import, paste, copy, clear, web translation and plugin management live in the round button's menu. Draft or language changes cancel stale requests, changed editor targets reject writeback, and sensitive fields such as passwords offer no translation. Existing web and optional offline plugin settings are retained.*
- **悬浮把手与缩放框**：拖动顶部中央把手移动键盘；点击把手显示四角和四条边，再次点击隐藏。缩放目标与按键分开，取消拖动恢复初始位置与尺寸；松手后保存有效调整。点击关闭按钮或工具箱开关可停靠。
  *Drag the centered top handle to move the floating keyboard; tap it to show four resize corners and four edges, and tap again to hide them. Controls stay clear of keys. Cancellation restores the starting geometry; completed adjustments are saved. Dock with the close button or toolbox toggle.*
- **候选与个人学习**：完整读音限制近期偏好与置顶候选，避免另一个完整拼音的词靠个人偏好抢首选；简拼、合法补全、纠错和邻键候选仍按各自规则排序。改善学习词进入长句与上下文联想的路径。
  *Complete readings constrain recent preferences and pins, preventing a word learned for another full reading from taking first place solely through personal preference. Abbreviations, valid completion, correction and touch-neighbor candidates retain their ranking rules. Learned words and contextual predictions also work better within longer input.*
- **打字与面板反馈**：完善空格滑动光标、候选横滑与抬手判定、英文 Shift 与大写锁定；长按退格删空英文组合后恢复句首大写。打开表情面板时顶栏按钮高亮，关闭或切换面板时同步更新；表情按分类浏览。
  *Improve spacebar cursor slides, candidate swipes/release handling, English Shift and Caps Lock. Repeated backspace restores sentence capitalization after clearing English composition. The emoji toolbar highlight follows panel opening, closing and switching; emoji browsing uses categories.*
- **手写**：Android 支持按字间停顿分组的叠写，连写和叠写均由用户点候选确认；完善异步识别、退笔、重做与个人纠正。单字自动上屏在退笔或重做后重新等待，不沿用旧截止时间。
  *Android overlay writing groups characters by pauses; both line and overlay modes require candidate confirmation. Improve asynchronous recognition, undo/redo and personal correction. Single-character auto-commit waits again after undo or redo instead of using the old deadline.*
- **语音与剪贴板**：多引擎识别结果可左右切换并打开全文，按结果质量选择初始项；完善最近复制或剪切内容在下一输入位置的粘贴建议。
  *Swipe among multiple recognition results and inspect their full text, with quality-based initial selection. Recent copy/cut content can be offered for pasting at the next input location.*
- **日期、计算与 u/v**：输入“时间”“日期”“星期”“今天”等对应拼音时，普通词后提供当前值；v 模式支持算式、金额、中文数字和千分位，接受常见全角运算符。正文算式后输入等号可选结果；u 拆字和笔画查字沿用现有入口。详见[快捷输入说明](../quick-input.md)。
  *Date/time/weekday words offer current values after the ordinary word. V mode supports arithmetic, financial amounts, Chinese numerals, digit grouping and common Unicode operators. Editor formulas followed by equals offer a result; existing u component/stroke lookup remains available. See [Quick input](../quick-input.md) for limits and examples.*

## 下载与升级 / Download and upgrade

- Android：`WeaveText-0.1.0-beta.27-arm64.apk`，Android 8.0+、ARM64，使用原正式签名覆盖升级。包含离线语音运行库，识别模型按需下载。
  *Android 8.0+, ARM64; upgrade with the existing release signing identity. Offline speech runtime is included, with recognition models downloaded when needed.*
- Mac：`WeaveText-0.1.0-beta.27-mac.dmg`，macOS 13+，Apple 芯片与 Intel 通用；安装包未作 Developer ID 签名和公证。
  *macOS 13+, universal for Apple silicon and Intel; the installer has no Developer ID signature or notarization.*
- 可选翻译插件：`WeaveText-Google-Offline-Translation-0.1.0.apk`、`WeaveText-Apple-Offline-Translation-1.0.0.zip`。插件无需因主应用升级而重新安装。
  *Optional translation plugins retain their existing versions and do not require reinstallation for this app update.*
- `SHA256SUMS.txt`、`SHA256SUMS-plugins.txt` 与 `SHA256SUMS-mac.txt` 提供相应文件的 SHA-256。
  *The checksum files cover the corresponding Android, plugin and Mac assets.*

## 验证范围 / Verification scope

本地 Rust release 工作区 267 项通过、0 失败、3 项忽略。Mac 构建中两组 Swift 测试分别为 60 项和 231 项通过，Universal app、安装包与磁盘映像自检完成。Android JVM 单元测试 1083 项全部通过。Android 14 模拟器完成设备验收：34 项设备测试 32 项通过、1 项按条件跳过（需要配对的 Mac 端）；语音设置流程另做 8 次连续复跑全部通过，翻译插件、拼音注音与剪贴板建议在前一轮发现的问题均已修复并复验通过。互联 NSD 发现用例依赖模拟器 Wi-Fi 组播，当前主机上各模拟器的虚拟 Wi-Fi 均未联机（其他项目的模拟器同样如此），该项沿用本轮改动前的整机通过记录。

The local release Rust workspace passed 267 tests, with zero failures and three ignored. The Mac build passed Swift groups of 60 and 231 tests and checked the universal app, installer and disk image. All 1083 Android JVM unit tests pass. Device acceptance on an Android 14 emulator: 32 of 34 device tests passed and one skipped as designed (it needs a paired Mac); the voice settings flow also passed eight consecutive stability runs. The translation plugin, pinyin reading and clipboard suggestion issues found in the previous round were fixed and re-verified. The link NSD discovery case needs emulator Wi-Fi multicast, which is currently down on every emulator on this host (including an unrelated project's), so its earlier full-run pass stands for this round.
