## 织文输入法 0.1.0-beta.5（预发布 / Pre-release）

第五个测试版：修复语音输入后的残留联想、拼音组合和退格问题，改进用户联想词删除，并继续优化手写输入。
仍在测试阶段，欢迎反馈。
Fifth test build: fixes stale predictions, composing text and backspace behavior after voice input, improves deletion
of learned predictions, and includes the latest handwriting improvements. Feedback welcome.

### 下载哪个 / Which file

| 文件 File | 说明 Notes |
|---|---|
| `WeaveText-0.1.0-beta.5-arm64-lite.apk`（约 33 MB） | **推荐。** 全部输入功能；需要离线语音时在「语音包」里一键安装。 *Recommended.* |
| `WeaveText-0.1.0-beta.5-arm64-voice.apk`（约 67 MB） | 内置识别运行库与实时识别模型，装好即可离线说话。 *Ships offline voice.* |
| `WeaveText-0.1.0-beta.5-mac.pkg` | macOS 13+，Apple 芯片与 Intel 通用。双击安装。 *Universal macOS installer.* |
| `WeaveText-0.1.0-beta.5-mac.dmg` | 内含同一个 `.pkg` 安装包。 *Disk image containing the same installer.* |

安卓两个包签名相同，可互相覆盖安装，也可直接覆盖旧版，设置与学过的词都保留。
*Both APKs share one signature and install over each other and older builds, keeping settings and learned words.*

### 新变化 / What's new

- **语音输入**：语音直接给出终稿时会先结束正在输入的拼音或手写组合；旧联想词会立即收起，连续退格可以正常删到空；语音会话结束或报错后，迟到的识别结果不会重新写回输入框。
  *Voice finals settle any typed or handwritten composition, dismiss stale predictions, and keep backspace reliable; late callbacks after a session ends are ignored.*
- **联想词**：长按删除用户联想词后立即刷新候选；剩余候选仍可正常选择；繁体输出下仍使用原始简体词和搭配学习键。
  *Deleting a learned prediction refreshes the list while keeping remaining candidates selectable; traditional output preserves the original learning keys.*
- **手写**：保留独立墨迹层、后台识别、切数字键盘先上屏，以及数字、字母和标点候选的融合优化。
  *Includes the separate ink layer, background recognition, commit-before-switching-to-numbers behavior, and improved fusion for digits, letters and punctuation.*
- **macOS**：预编辑显示自动纠错的红色标记。
  *Correction marks now appear in the Mac preedit.*

### 已知问题 / Known issues

- 主要在模拟器、桌面测试和截图中验证，真实录音、微信等第三方应用以及手写笔迹的实机跟手感仍需更多设备测试。
  *Verified mainly with emulator, desktop tests and screenshots; real-device recording, third-party apps and handwriting feel need more device coverage.*
- beta.5 离线语音版存在正式包混淆导致模型加载失败的问题（`failed to get field ID for decodingMethod`），修正版为 beta.6；重新下载模型不能修复此问题。
  *The beta.5 offline-voice APK has an R8/JNI field-name bug fixed in beta.6; re-downloading models does not fix it.*
- Mac 安装包未经 Apple 开发者签名或公证；系统拦下时，到「系统设置 › 隐私与安全性」允许打开。
  *The Mac installer is unsigned and not notarized; allow it under Privacy & Security if macOS blocks it.*
