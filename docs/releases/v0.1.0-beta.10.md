# 织文输入法 0.1.0-beta.10

- 多模型语音候选保留三行，每行左右滑动查看全部文字；长按展开换行全文，左右切换模型、上下滚动，点「上屏」选择正在查看的结果。
- 默认中英混合，新增中文、English 模式；设置页和语音面板均可切换，各语言独立记住模型选择。语言参数直接更新识别器，不靠删除其他语言文字来伪装识别。
- 新增 Whisper 基础、增强终稿模型，英文补强推荐增强模型。混说优先专门的双语 Zipformer，也可同时选模型比较结果。
- 键盘出现时真正预载语音模型，优先准备主模型。隐藏键盘不会误清语音和词库缓存；语音模型闲置 20 分钟或真正内存紧张时才释放。
- 模型加载串行安排，识别线程按同时选中的模型数分配；缓存复用时不重新读取权重，每次录音使用新的音频状态。Whisper 只整句解码，减少重复处理与积压。
- 手写在纠正候选后适应相似字形，记录仅保留于当前输入法进程；不将半个字套成已学习的完整字。隐私输入框关闭适应，立即删除纠正的字会撤销该次适应。
- 横屏语音面板将音量条放到麦克风旁，给实时文字留出空间。
- 手写缓存已完成笔画的轮廓，移动时处理当前笔画，保留原来的笔锋和删除、重写行为。
- 包含 Android Lite、离线运行库版，以及 Mac 通用 PKG／DMG。

Whisper 基础压缩包约 208 MB，模型约 161 MB；增强压缩包约 639 MB，模型约 375 MB，逐文件来源可能更小。识别模型仍需另行下载。

语言和识别链路已用实际 WAV、正式 APK 和回归测试验证。增强 Whisper 在英文测试句中正确识别了 tribal chieftain，数字会规整为 50；正式包麦克风录音仍出现 chieftain → chief then 的错词。混说仍有英语粘连、漏字和中文错字，不能保证所有口音和环境完美准确。候选全文可用于比较后选择。
