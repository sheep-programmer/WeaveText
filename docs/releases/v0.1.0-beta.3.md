## 织文输入法 0.1.0-beta.3（预发布 / Pre-release）

第三个测试版：打字更准不误触、上屏后有联想、专业词库与云端热词、手写，以及全新的 macOS 版和手机电脑互联。
仍在测试阶段，欢迎反馈。
Third test build: fewer mis-taps, next-word prediction, domain dictionaries and cloud hot words, handwriting, plus a
new macOS app and phone ↔ computer WeaveLink. Feedback welcome.

### 下载哪个 / Which file

| 文件 File | 说明 Notes |
|---|---|
| `WeaveText-0.1.0-beta.3-arm64-lite.apk`（约 33 MB） | **推荐。** 全部输入功能；需要离线语音时在「语音包」里一键安装。 *Recommended.* |
| `WeaveText-0.1.0-beta.3-arm64-voice.apk`（约 67 MB） | 内置识别运行库与实时识别模型，装好即可离线说话。 *Ships offline voice.* |
| `WeaveText-0.1.0-beta.3-mac.dmg` | macOS 13+，Apple 芯片与 Intel 通用。打开后双击「织文输入法」即可安装。 *Double-click to install.* |

安卓两个包签名相同，可互相覆盖安装，也可直接覆盖旧版，设置与学过的词都保留。
*Both APKs share one signature and install over each other and older builds, keeping settings and learned words.*

### 新变化 / What's new

- **不再老误触**：按实测重调 26 键比例（功能键加宽、行距加高、字母回到键中心），按在两键交界处时自动纠正到能拼成音节的那个键；
  手机横屏不再分体，导航栏不会再盖住键盘。
  *Retuned proportions, centred letters, border taps corrected to the key that spells pinyin; no split on phones in
  landscape; the navigation bar no longer covers keys.*
- **联想与学习**：上屏后推荐下一个词，选过的搭配会记住；久不用的词慢慢回到原位，选错马上退格即撤销学习，连着打的两段会记成新词。
  *Next-word prediction; learning fades, undoes on an immediate backspace, and learns phrases typed in pieces.*
- **专业词库**：医学、药品、化学、动植物、IT、财经、法律、汽车、地名、诗词成语、历史人物、饮食、影视艺人、方言，按需下载、随时删除，
  不会挤掉常用词。 *14 domain dictionaries, downloaded and removed one by one.*
- **云端热词**（默认关闭）：每天从公开的织文热词库下载一次新词，签名校验，只下载不上传。 *Optional signed hot words.*
- **织文互联**：手机与电脑（macOS 版）扫码配对，互传文字、图片、文件，剪贴板双向同步，端到端加密、不经服务器；
  任意应用「分享 › 发送到电脑」，键盘工具箱「发到电脑」。 *Pair by QR, send text/images/files, sync the clipboard.*
- **手写**：单字手写，笔顺不限、可连笔。 *Handwriting input.*
- **实用候选**：`v1234` 出大写金额与中文数字，`v` 加算式出结果，`rq` / `sj` / `xq` 出日期时间星期，敲等号给出算式结果；
  成对符号；复制带验证码的短信时候选栏只给出验证码；光标面板加撤销、重做、按词移动。
  *Uppercase amounts, arithmetic, date/time, paired punctuation, one-time codes, undo/redo in the cursor panel.*
- **macOS 版**：同一内核，候选窗跟随光标、菜单栏图标（左键菜单、右键设置）、SwiftUI 设置，支持联想、专业词库、云端热词与互联。
  *The macOS input method on the same engine.*

### 已知问题 / Known issues

- 主要在桌面测试与截图中验证，真机覆盖有限。 *Verified mainly on desktop tests and screenshots.*
- macOS 版未经 Apple 公证：首次打开若提示无法验证开发者，请右键 › 打开，或在「系统设置 › 隐私与安全性」里点「仍要打开」。
  *The Mac app isn't notarized: right-click › Open the first time, or allow it in Privacy & Security.*
