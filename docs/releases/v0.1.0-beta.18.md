# 织文输入法 0.1.0-beta.18

- 修复英文语音档位：此前该档位排除了中英双语实时模型，只有 SenseVoice 与 Whisper 可选。装了中英双语模型时切到英文档，可用引擎列表变空，界面同时显示「未选择引擎」与「请先下载离线语音包」，看起来像下载了也没用。现在英文档位接受所有能识别英文的模型。
- 中英混合档位下，曾经单独选中的中文专用模型不再锁死整个档位：已装双语模型时自动改用双语模型。
- 自动下载按当前档位补模型：中英混合／英文档取双语实时模型，中文档取中文实时模型；切换档位时若缺模型会就地开始下载。
- 修复语音面板文字重叠：面板较矮时中间文字区的下边界会落回顶部语言档位行，状态文字因此压在「中英混合／中文／English」上。
- 「没有可用模型」的说明不再与麦克风下方提示重复同一句话。
- 表情收纳袋管理页改用与设置页同一套界面风格（配色、圆角、卡片、按钮），不再是系统原生控件的外观。
- 输入法内的收纳袋面板整体收紧，深色与浅色主题下都不会再被键盘高度裁掉。
- 长按表情可直接收藏、编辑、分享、删除，不再强制跳转到全屏管理页；「悬浮」直接打开悬浮窗。

包含统一 Android arm64 APK（内置离线语音运行库，识别模型按需下载），以及 Apple Silicon／Intel 通用 Mac PKG、DMG。
