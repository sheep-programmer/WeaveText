# 织文输入法 0.1.0-beta.17

- Android 发布统一安装包，内置离线语音运行库，取消 Lite／语音版区分。识别模型不放进 APK，第一次点语音时自动通过镜像下载默认中英混合模型。
- 默认自动选择中英双语实时模型，修复已有中文模型被优先保留导致英文始终按中文识别的问题。中英混合模式会明确切换到双语模型；英文模式仍可选择 Whisper／SenseVoice。
- 关于页新增“在线检查更新”：读取 GitHub Release，按直连和镜像顺序回退，下载时校验 SHA-256 与应用签名，再交给系统安装器。
- 仍支持语音页手动选择和下载其他识别模型，最多同时启用三个模型。

包含统一 Android arm64 APK，以及 Apple Silicon／Intel 通用 Mac PKG、DMG。
