# 织文输入法 0.1.0-beta.11

- Android、Mac 互联页可直接选择发送文字、剪贴板、图片或文件及目标设备。
- 两端可选择各自接收目录，默认下载目录；Android 使用系统文件夹授权，失败时保留原文件，可重新保存或转发。
- 修复 Mac 复制图片被附带文字覆盖、Finder 文件不参与同步的问题；图片和任意文件类型可跨设备进入剪贴板。
- Android 媒体剪贴板历史保存独立副本，支持缩略图、固定、删除和转发；支持真实图片粘贴的编辑器可直接接收，其他编辑器通过系统分享转发。历史仍需用户主动开启，密码框和敏感剪贴板继续过滤。
- Android 系统分享目标明确显示「WeaveText · 发送到设备」，后台读取有授权的内容后发送，避免云盘／相册临时流被误发为空文件。
- Android 改用系统 NSD，Mac 改用系统 Bonjour；支持 IPv4／IPv6，扫描不会一直转圈，新增重试、权限入口和失败提示。修复 Mac IPv4 端口已占用时 IPv6 监听可能连接到另一进程的问题。
- 增加直接地址配对、地址更新重连，以及 Mac 公网地址配对二维码。远程传输不经过本项目服务器，但需要公网 IPv6、IPv4 端口映射或已有直连 VPN；双端运营商 NAT 后不能保证无服务器直连。
- 包含 Android Lite、离线语音运行库版和 Mac 通用 PKG／DMG；语音识别模型仍按需下载。

已验证：核心 IPv4／IPv6、目录与重连测试，Mac 系统 Bonjour 和图片／文件剪贴板表示测试，以及专用 Android 模拟器上的系统 NSD、Mac ↔ Android 图片解码、文件字节、剪贴板 URI、历史重读、下载目录与回传。尚未覆盖所有品牌真机及不同运营商网络。

使用方法及权限、远程网络条件见 [跨设备说明](https://github.com/sheep-programmer/WeaveText/blob/main/docs/cross-device.md)。
