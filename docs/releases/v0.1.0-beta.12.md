# 织文输入法 0.1.0-beta.12

- 修复“同一个字已选用五次，下次仍排在后面”：排序结合旧累计词频和近期明确选择，相同读音反复确认的字词优先；全拼、双拼、九键共享学习记录。
- 对完整输入的个人候选保留优先权，避免自动组句挡在它前面；单字偏好不把更长输入的整句挤走。选过的组合词句也会作为整体学习。
- 上屏完成即写入本地日志，换输入框和重新加载后继续保留。选错立即退格恢复此前词频、近期偏好及搭配，关闭学习时不积累偏好。
- Mac 的英文模式接入单词补全，修复英文按键一直直通、看不到建议的问题。Android 普通文字输入框继续提供英文补全。
- 英文补全支持本机使用过的新词、近期选择排序和大小写。下一词联想包含常见搭配和本机学到的词对，个人搭配优先。
- 点选英文单词不会再自动加空格；只有手动按空格才输入空格。保留原始拼写，避免接受空格或标点时擅自换成其他补全。
- 修正设备快速重启时端口可用性检查可能误判、导致已配对设备重连失败的问题。
- 学习仅在本机保存，密码框与禁止学习的输入框不积累记录；清空用户词库也清除英文个人记录。

已验证：核心跨方案回归、实际中文／英文词库的 JNI 和 Mac C ABI、手机控制器与安装包内词库。实际词库示例 `shi → 嗜`，旧高词频下五次选择后仍为第三，新版重复确认后成为首选，独立重新加载仍是首选。200 句中文评测的首选和前三命中率与 beta.11 相同。

英文下一词联想使用少量常见搭配和本机历史，不是大型英文语言模型。输入框明确关闭建议时仍尊重其规则。Mac 与各品牌手机的应用兼容性仍需持续验证。

包含 Android Lite、离线语音运行库版及 Mac 通用 PKG／DMG。开源调研、实现说明和验证方法见 [个人学习与英文补全](https://github.com/sheep-programmer/WeaveText/blob/main/docs/learning-and-english.md)。
