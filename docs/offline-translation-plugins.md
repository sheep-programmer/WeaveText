# 独立离线翻译插件

2026-10-06。在线网页入口保留在主输入法，默认无需下载。离线引擎和语言包是独立可选项，不能把“打开离线开关”冒充独立插件。

## Android

安装主输入法后，在设置 → 翻译 → 离线翻译插件中选择配套插件 APK，完成 Android 的安装确认。也可以直接安装插件 APK。返回后状态会立即刷新；只有签名匹配、协议兼容且启用的插件才会用于翻译。

点“管理语言包”进入独立插件应用，按语言下载或删除。默认 Wi-Fi，可明确允许移动网络。Google 官方语言包约 30 MB，具体占用由 SDK 管理。主输入法本身不含 `libtranslate_jni.so`、`liblanguage_id_l2c_jni.so`、Google ML Kit 或模型。插件卸载由系统确认，插件应用及其私有语言包随卸载删除；主输入法和个人词库保留。

翻译只使用已安装的语言包。缺少语言包返回 `MODEL_MISSING`，提示先去插件管理，**不会自动下载**，也不自动把文本转发给网络服务。语言识别模型在插件 SDK 中，原文由插件在设备处理。Google SDK 的模型下载与诊断信息可能联网；其 SDK 不是开源引擎。

插件单独安装后也有应用图标，可以自行打开管理语言包。引擎 APK 采用相同签名和受保护的 Binder 服务；基础契约在 `android/translation-contract`，不含 SDK。请求有长度上界、版本检查、来源签名检查、请求 ID 和取消，卸载/升级/断开不会使旧结果写回新输入框。

Google 仅支持英语枢纽的现有设备模型，非英语语言之间会经英语中转。英语由 SDK 提供，无需额外英语包；其他语言分别管理。依据 [Google 模型管理文档](https://developers.google.com/ml-kit/language/translation/android)，下载、列出、删除采用 `RemoteModelManager`；没有第三方模型镜像或伪造安装状态。SDK 管理的下载可能在取消界面任务后继续。

## Mac

独立包 `WeaveText-Apple-Offline-Translation-1.0.0.zip` 含 `manifest.yaml` 与 `main.lua` 适配描述，声明系统引擎、类型、版本及 macOS 15 最低要求。可以在翻译设置中手动导入 ZIP、描述目录或原清单；按内容识别，不固定文件后缀。独立安装池是用户目录的 `translation-plugins`，与语音和其他插件分开。

安装后再启用 Apple 离线翻译；未安装、未启用或系统不支持时不能调用 Native。可以在管理页准备所选语言包，由 macOS 显示实际系统授权提示。适配包 **不包含语言模型或 Apple SDK 的可下载副本**，系统语言包由 Apple 管理。卸载只删除适配插件，不删除共享系统语言包或其他插件。

默认仍是 Google 官方网页。网页结果需手动复制返回，不使用非公开接口或抓取页面结果。两端的选区绑定、取消与密码输入保护保留。

## 本轮验证

Android 主应用 56 项定向回归、独立插件 38 项引擎/协议/取消回归通过；Mac 全套 223 项通过。Android 36.1 独立模拟器实际安装两个 APK，通过 Binder 验证缺包不下载、明确下载官方中文包、跨进程中译英/自动英文译中文、删除语言包后再次返回缺包，以及真实编辑器的跨框拒绝与密码禁用：3 项设备测试通过。

主 APK 与插件 APK 的正式签名匹配；主 APK 的 Google 翻译和语言识别 JNI 均不存在，Sherpa 语音 JNI 字段检查保留。Mac 用实际独立 ZIP 验证安装、启用、禁用、卸载、最低系统要求与描述校验；正式包双架构自检保留。有限合成文本不是所有语言或场景的翻译准确率评测。
