# 跨设备输入与文件传输

Android、Mac 开启「互联」后，可以在同一页面选择发送文字、当前剪贴板、图片或文件及接收设备。Android 也能在其他应用的系统分享菜单中选择「WeaveText · 发送到设备」。长按图片或文件后，先打开该应用的「分享」；软件不能替其他应用修改其私有长按菜单。

接收目录默认是下载目录。Android 通过系统文件夹选择器单独授权目录，保存持久授权，不要求「所有文件访问权限」；Android 8–9 的默认位置是应用专属下载目录。Mac 可选择本机可写目录。接收目录变更适用于后续新文件。目录授权失效或写入失败时，Android 保留原文件，可重新选目录后「重新保存」，也可转发。

## 剪贴板

Mac 按文件、图片、文字的顺序读取剪贴板表示，避免 Finder 图标覆盖文件、网页图片附带的 URL 覆盖图片。手机接收图片或文件后使用带 MIME 类型的内容 URI 写入剪贴板。Android 的复制检测只在系统允许输入法读取剪贴板时运行；后台普通应用无法持续读取其他应用的剪贴板。请将织文设为当前输入法，或直接使用系统分享。

Android 剪贴板历史默认不记录，开启后可保存文字、图片和任意文件类型，未固定项默认保存 24 小时。媒体由应用保存独立副本，不依赖相册临时 URI 或互联临时文件。媒体历史总量上限 512 MB；超过单文件上限请直接发送文件。密码及禁止个性化学习的输入框不记录、展示剪贴板历史；敏感剪贴板不自动同步。只显示当前剪贴板时不生成媒体历史。

点击图片卡片会尝试向支持该 MIME 的输入框提交真实内容；编辑器不支持图片／文件粘贴时，打开系统分享面板。长按媒体卡片可固定、转发或删除。远端剪贴板内容不自动回传。

## 设备发现与权限

Android 使用系统 NSD，Mac 使用系统 Bonjour，广播 `_weavelink._tcp` 并解析 IPv4／IPv6 地址。扫描在 12 秒后结束等待状态，后台仍监听设备变化；可手动重新扫描。服务失败和地址解析失败有明确提示。

两端需要开启互联。访客 Wi-Fi、路由器 AP 隔离、公司网络禁用组播、防火墙及本地网络权限都可能阻止自动发现。发现失败仍可扫码或输入地址配对。Mac 的本地网络权限在「系统设置 › 隐私与安全性 › 本地网络」管理。Android 的目录、附近设备及通知授权在互联页管理。

当前 target SDK 36；Android 16 的本地网络限制是可选择启用的，受限设备可授予附近设备权限。Android 17 为 target SDK <37 的应用保留临时隐式网络授权；日后升级 target SDK 37 时须迁移到 ACCESS_LOCAL_NETWORK。依据：[Android 官方本地网络权限说明](https://developer.android.com/privacy-and-security/local-network-permission)。

## 不经过服务器的远程连接

可以使用公网 IPv6、映射到监听端口的公网 IPv4，或已有的直连 VPN。地址写法为 `IPv4:端口` 或 `[IPv6]:端口`。本机默认监听 47811，端口被占用时会选择其他端口，请以配对窗口显示的端口为准。

Mac 可填写「本机公网地址」，配对二维码会使用该地址。Android 可生成本机配对码，让 Mac 输入其可达地址及配对码。地址变化后，在已配对设备上更新直接地址并重连；已配对公钥继续核验，无需重新信任设备。

本实现不使用公共信令、STUN 或中继服务器。两端都在运营商 NAT／无法开放入站的网络后时，不能保证任意网络直连；通用 NAT 穿透常需外部协调，部分情形必须中继。依据：[RFC 5128](https://www.rfc-editor.org/rfc/rfc5128.html)。二维码可以传递配对资料，但不能解除路由和防火墙限制。

## 验证

Rust 回归测试覆盖 IPv4、IPv6、配对、持久重连、自定义接收目录和图片／任意文件的字节传输。Mac 可用 `WEAVE_TEST_BONJOUR=1 swift test ... --filter LinkBonjourTests` 运行系统 Bonjour 测试。

Android 构建 `:app:assembleDebug :app:assembleDebugAndroidTest` 后，将两个 APK 安装到专用测试设备，编译 `cargo build -p weave-link --example link-probe`，运行 `python3 tools/link-device-check.py --serial <测试设备>`。真机可用 `--host <可达的电脑地址>`。测试会写入测试设备剪贴板和下载目录，验证系统 NSD、Mac ↔ Android 图片／文件字节、媒体历史重读及回传；请勿使用存有私人资料的日常设备。
