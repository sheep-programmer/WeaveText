# Mac 与手机功能对照

2026-10-06，0.1.0-beta.20。本轮补齐桌面入口与设置，两端保留各自适合的平台行为。

| 功能 | Android | Mac |
| --- | --- | --- |
| 全拼、简拼、中英混输、纠错 | 共用 Rust 内核 | 同一内核；新增纠错开关，默认开，切换即时刷新当前组合 |
| 双拼 | 小鹤、自然码、微软、搜狗 | 已补搜狗，与手机相同 |
| 五笔 | 四码上屏、z 键拼音反查、编码补全 | 新增各项开关 |
| 候选操作 | 点击、展开、翻页、动态学习、降权、删除学习 | 鼠标与快捷键均可用，已有的展开点击修复保留 |
| 组合串编辑（2026-10-13） | 点按／拖动预编辑行或空格滑动移动插入点；外接键盘方向键、Home／End、Delete，Ctrl 加方向键／删除键按音节；退格撤回刚选的词；长按候选或 `[`／`]` 以词取字；展开候选可只看单字 | 点击文档里的拼音放插入点（应用报告点在标记文字里时）；竖排时方向键、两种排列都可用 Home／End／Delete，⌥ 加方向键／删除键按音节；退格撤回与 `[`／`]` 取字相同；展开网格有「单字」开关 |
| 字形筛选（2026-10-13） | 拼音后按 `` ` `` 接笔画或部件拼音；展开候选下方有横竖撇点折笔画键 | 实体键盘同样按 `` ` ``（内核相同）；展开网格暂无笔画键 |
| u 模式拆字查字（2026-10-13） | 全拼 u 后打部件拼音或笔画，候选注读音 | 相同（内核相同） |
| 光标编辑与大写锁定（2026-10-13） | 光标面板含选择、复制、剪切、粘贴、全选；英文双击或长按 Shift 锁定大写，切中文自动解除 | 系统文本编辑快捷键；Caps Lock 直通大写 |
| 拼音注音 | 默认关；打开后只在首选后用括号标完整声调；展开只显示词 | 默认关；打开后只标高亮候选，规则相同 |
| 个人学习 | 简拼、云词、搭配、手写学习 | 同一内核；新增学习开关，学习默认开 |
| 联想与英文补全 | 按手机原设置 | 按用户要求两项默认关闭，英文直接原样输入；开启后数字只选词 |
| 桌面外观 | 手机布局与主题设置 | 四套配色，浅色/深色/跟随系统，全窗口即时切换 |
| 用户词管理 | 搜索、添加、删除、导入导出 | 补齐添加和文本导入导出，格式与手机相同 |
| 专业词库、云热词 | 按需下载、验签、学习 | 已有；共用数据与下载镜像 |
| 快捷短语与模板 | 输入码候选、工具面板 | 已有编辑页；新增可直接点选的悬浮窗，日期/时间由内核展开 |
| 剪贴板历史 | 默认不记录；固定、删除、媒体记录 | 新增同类能力；未固定 50 条/24 小时，敏感剪贴板与安全输入不记录 |
| 翻译 | Google 官方网页默认；独立离线插件 APK，语言包下载/删除在插件内，主 APK 不含 SDK | Google 官方网页默认；独立 Apple 适配插件 ZIP，系统语言包由 macOS 管理，15+ |
| 常用语 | 添加、固定、点击上屏 | 新增管理页与打字时的悬浮窗 |
| 手写 | 单字、连写（写完一行点候选上屏）、单字停笔上屏、学习清理 | 已有触控板/鼠标手写窗；补齐连写偏好保存与即时同步，连写同样不按停笔上屏 |
| 语音插件 | Lua 宿主、配置、多个引擎 | 新增同一宿主的 C/Swift 接口与配置列表，最多三个引擎共用录音 |
| 插件仓库 | 可展开数量列表、完整链接、私有仓库 PAT | 补齐同类列表，PAT 保存到 Mac 钥匙串 |
| 手动插件导入 | 按 ZIP 与清单/入口内容识别 | 同样按内容识别；两端不限制包文件后缀 |
| 语音音频 | 16 kHz、单声道、16 位 PCM | 麦克风音频转换为同一格式，可运行相同的语音插件 |
| 离线语音 | sherpa 模型包、离线模型选择 | 系统离线语音；检查语言资源可用性。尚不加载 Android 的 sherpa 模型包 |
| Emoji 与颜文字 | 共享 1898 个 Emoji、132 个颜文字及中文名称；长按名称提示 | 同一离线目录与独立选择窗口；长按或悬停显示名称 |
| 表情收纳 | 收藏、分组、备份；管理页、键盘面板与悬浮窗里的动图都播放 | 已有桌面收纳袋及互通备份；缩略图播放动图 |
| 候选排序 | 长按候选可置顶、降频、恢复；展开网格有「单字」与「一丨丿丶乛」笔画键 | 右键候选项可置顶、降频、恢复；展开网格同样有「单字」与笔画键 |
| 个人资料 | 互联合并、备份格式 | 新增文件导入/导出；已有互联的合并入口，格式一致 |
| 互联 | 局域网、二维码、跨网连接码、剪贴板/文件 | 已有；共用 QUIC 与 UDP 打洞，无法直连时明确失败，不经过数据中转 |

九键/14 键、单手软键盘、按键音、震动、气泡和系统导航栏避让属于手机的触屏键盘。
Mac 使用实体键盘、鼠标候选窗和手写/语音/输入工具悬浮窗。Mac 的词库下载当前仍使用顺序镜像尝试，
尚未复刻 Android 的镜像测速、断点续传与模型管理页。

测试覆盖真实词库纠错与即时刷新、原始字母上屏、英文数字选词、长串乱打组合长度、
原生 Lua 插件导入/配置/识别、非标准后缀仓库包、剪贴板固定/过期/媒体清理，以及麦克风采样格式转换。
GitHub 账号测试使用受控响应和虚构令牌；构建不修改系统安装的输入源。
