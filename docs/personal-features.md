# 候选、重选、混输与个人资料

## 操作入口

手机长按候选可固定为首选或降权；Mac 右键候选有同样操作。固定按当前读音／输入码生效，不会把单字挤到更长整句前面。英文原始输入保留在最前，明确点选补全或纠错才改为建议词，仍不自动加空格。敏感输入框不读取或积累个人偏好。

选中已输入的汉字后，手机打开光标面板点“重新选词”；Mac 从系统输入法菜单点“重新转换所选文字”。当前汉字重选最多八个字，使用词库读音；多音字优先采用词库中的词组读音。编辑器必须支持读取选区。点选只替换原选区，移动选区后取消，重新输入或退出也恢复原方案。

英文拼写建议在前缀补全没有结果时使用有上限的 Damerau–Levenshtein 搜索，支持相邻字母颠倒等一至两处错误。原拼写始终保留。英语词表和少量下一词搭配来自已有数据，没有新增大型语言模型。

全拼中可以输入 `jintianreviewzhegePR`，一起选“今天review这个PR”。英文词典中的非拼音片段、已学英文词和大写缩写参与组句，保留原大小写与词内撇号；能够完整读成中文拼音的片段优先作为中文。全拼之外的方案保留原解码方式。

## 个人资料与快捷短语

在两端的互联页面，向在线且已配对设备发送个人资料；接收端点“合并个人资料”生效。内容是中文／英文个人词、近期选择、候选固定与降权、快捷短语、手写纠正样本。普通应用设置、语音模型和文件接收目录不在此包内。

沿用 Noise 加密配对连接，接收文件保存到互联状态目录中的 `personal-inbox`，不会放进公共下载目录或剪贴板。最多 8 MB；正在组合时拒绝合并，避免移动手指下的候选。固定候选与近期选择每个读音只保留一个记录，通过逻辑版本与设备标识确定冲突结果；删除留空记录，防止旧设备把已删内容带回来。词频取绝对记录，不把每次导入当成新使用次数。这是主动发送／合并，不是后台自动上传或完整设置同步。

在“词库 → 快捷短语与模板”设置 1–24 个字母的输入码，例如 `dz`。输入这个码，从候选插入常用地址；模板里的 `{date}` 和 `{time}` 按本地时区自动替换。点已有短语可编辑，清空内容后保存即删除。

## 手写

纠正后的字形记在私有的 `personal.json`，重新加载后仍可用。手机在输入方案页开启“多字连写”，Mac 从系统输入法菜单打开手写窗口。横向写 2–4 个字，字间留空；贴得很近的部件仍按同一个字识别。多字模式不按停笔时间自动上屏，由用户点候选确认。

手机输入方案页和 Mac 词库页可清空个人手写样本，同时取消手写候选的固定／降权。取消或立即退格使用现有撤销逻辑，不让误选永久变成新字形。识别模型继续缓存，Mac 后台只计算候选，主线程检查笔迹版本及当前输入框后才应用结果。

## 离线语音个人热词

离线语音配置中的“个人语音热词”默认关闭。开启后可录入人名、地名、术语，也读取本机学过的常用词。自定义词优先，去重后最多 256 项；不上传。

中文上下文偏置仅适配 transducer 模型，并使用 `modified_beam_search`；标准中英模型通过对应原始 `bpe.model` 的分词片段支持英文热词。增强中英模型未配置其对应的英文分词表，目前只提供中文热词；CTC、SenseVoice、Paraformer、Whisper 不调用这套接口。具体识别效果仍取决于音频和模型。

下载并加载模型之后，词汇变化写入私有文件，在新录音时创建带更新词汇的识别流，复用已经加载的声学模型。Lite 使用 sherpa C API，语音运行库版使用对应 Kotlin 接口；两条路径都保留原有录音、波纹、多候选和按住说话逻辑。

## 可复现验证

- `cargo test --workspace`：完整音节与显式分隔、学习撤销、同音英文保护、双设备冲突／重复合并、错误读音码、持久手写字形及多字候选。
- Android `LearningDeviceTest`：安装包词库、真实 `InputController` 与 `EditText`，检查只改选区、相同文字换选区后取消、固定重载、`ken`、混输和英文无空格上屏。
- `tools/link-device-check.py --serial <独立测试设备>`：系统 NSD、图片／文件剪贴板与下载目录，以及私有个人资料双向传输、接收端合并和回传新短语。
- `tools/voice-hotwords-check.py <设备> <标准中英模型目录> [--runtime <arm64运行库目录>]`：对已安装的正式 APK 连续识别两次并更新词汇，验证中英文实际文字；需要同签名的 `:voice-smoke:assembleRelease`。
- Mac 构建脚本测试实际 C ABI 与内置词库，并生成两种架构的安装包、自检及签名校验。

中文回归使用 `c519d02` 的独立基线、相同的拼音／英文词库和字符搭配模型，1000 句首选、前三及字符准确率保持一致。源码与模型的来源、转换方式见 `docs/THIRD_PARTY.md`。
